# Installation

Copy the desired skill folders under `skills/` into your agent's skills directory.

Recommended default set for a requester application:

```text
meripehchaan-integration-architect
meripehchaan-oauth-pkce
meripehchaan-account-identity
meripehchaan-apaar-education
meripehchaan-file-apis
meripehchaan-pull-documents
meripehchaan-meta-apis
meripehchaan-security-consent
meripehchaan-testing-debugging
meripehchaan-integration-reviewer
```

Install `meripehchaan-push-uri` only for systems that truly act as a registered DigiLocker Issuer.

Keep the `reference/` directory beside `skills/`, because the SKILL files link to it with relative paths.
